# ❤️ Heart Disease Prediction System

## 📌 Project Overview
The Heart Disease Prediction System is a Machine Learning-based web application designed to analyze patient medical data and predict potential heart disease risks. It uses a Random Forest Classification algorithm to generate predictions based on various health parameters.

The application provides an interactive interface for entering patient details and viewing prediction results along with visual insights.

## 🚀 Features
- Patient medical data input
- Heart disease risk prediction using Machine Learning
- Random Forest Classification
- Data preprocessing and feature scaling
- Interactive prediction results
- Correlation heatmap
- Heart disease distribution visualization
- Feature importance graphs

## ⚙️ Installation and Setup

1. Clone the repository:
```bash
git clone https://github.com/madhuriyay/Heart-Disease-prediction.git
```

2. Navigate to the project folder:
```bash
cd Heart-Disease-prediction
```

3. Install the required dependencies:
```bash
pip install -r requirements.txt
```

4. Run the application:
```bash
python app.py
```

5. Open the application in your browser at:
```text
http://127.0.0.1:3003
```
